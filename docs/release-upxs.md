v1.0.3：统一通过根目录 `build.sh` 构建前端，npm 包名调整为 `@farfarfun/utools-funlink`；插件显示名和用户数据格式不变。

一链即达 UPXS 正式版，官方插件项目 ID：`zvghtljr`。

下载 `utools-funlink-1.0.3.upxs` 后导入 uTools。此包通过 GitHub Actions 构建，使用统一的 `utools-devtools` 生成，并完成认证解密、清单资源、插件 ID 和 ASAR 完整性校验；提供 `SHA256SUMS` 核对下载文件。

此前版本修复网页快开开关状态和说明，支持自定义正则匹配主搜索输入，并可用网址中的 `{q}` 接收完整输入内容。旧版 `%7Bq%7D` 占位符、v1 存档和「网址精灵」备份仍可用。保存失败时会回滚未落盘的改动和快开入口；备份、WebDav、图标获取与链接检查的失败反馈也已修正。

三个敏感字段由组织 Secrets 注入，仓库只保存公开的项目配置。相同打包链路已由用户在 FunCalc 上实机安装验证；本插件自身的安装和功能仍待实机确认。
